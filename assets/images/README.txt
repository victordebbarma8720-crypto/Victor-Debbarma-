This folder holds the site's images (all original artwork). Hostinger is
case-sensitive, so keep these exact lowercase names when replacing a file:

  logo.svg      - logo (also the SVG favicon)
  logo.png      - logo, header and footer
  favicon.png   - browser tab / home-screen icon
  hero.svg      - homepage hero illustration
  og-image.jpg  - social-share image (1200 x 630)

If a file is missing, the website hides that image automatically.
