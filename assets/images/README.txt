Put your three image files in THIS folder (public_html/assets/images/) with these
EXACT lowercase names. Hostinger servers are case-sensitive: "logo.PNG" is not "logo.png".

  logo.png     - site logo (header and footer)
  hero.png     - homepage hero image and social-share (Open Graph) image
  favicon.png  - browser tab icon (square, e.g. 512 x 512)

Until a file is uploaded, the website hides that image automatically and shows the
text logo instead, so nothing looks broken.
