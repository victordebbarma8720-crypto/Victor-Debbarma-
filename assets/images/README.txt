Put your image files in THIS folder (public_html/assets/images/) with these
EXACT lowercase names. Hostinger servers are case-sensitive: "logo.PNG" is not "logo.png".

  logo.png     - site logo (header and footer) (ALREADY INCLUDED)
  hero.jpg     - homepage hero + social-share image (ALREADY INCLUDED)
  favicon.png  - browser tab icon (square) (ALREADY INCLUDED)

Until a file is uploaded, the website hides that image automatically and shows the
text logo instead, so nothing looks broken.
